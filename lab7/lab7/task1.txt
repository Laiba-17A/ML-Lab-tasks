Task 1 - Fair Experiment Setup

Features: Glucose and BMI (two numeric predictors so decision boundaries can be plotted in 2D).
Target: Outcome (0 = no diabetes, 1 = diabetes).

Class balance: about 65% class 0 and 35% class 1, so the data is imbalanced. A stratified 80/20 split
(random_state=42) keeps the same ratio in train and test sets.

Zero values: Glucose, BloodPressure, SkinThickness, Insulin and BMI cannot realistically be 0 in a living
person, so zeros in these columns are treated as missing (NaN). They are filled with the median of the
training set only. Median is used because it is robust to outliers and skewed values (e.g. Insulin).

Scaling: StandardScaler is fit on the training set only and then applied to both train and test sets.

Why leakage invalidates the comparison: if medians or mean/std were computed on the full dataset,
information from the test set would enter training. The test set would no longer be truly unseen, so
scores would be optimistically biased and would not reflect real performance on new patients. Since both
models must be compared on the same fair held-out data, any leakage could also favour one model unfairly
and make the comparison meaningless.

The prepared arrays are saved in data.npz (xtr, xte, ytr, yte) so Tasks 2-4 use exactly the same data.
